# Wolfie — Animated AI Companion

A static portfolio page about designing Wolfie, Ish Singh’s animated AI companion. The page includes the character animation gallery, design process, desktop mockup, and links for creating a companion concept.

## Preview locally

From this folder, run:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>. The page has no build step or external dependencies.

## Upload to GitHub

Create a repository, extract this ZIP, then upload the contents of `wolfie-ai-companion/` to the repository root (or commit and push them with Git). To host with GitHub Pages, choose **Settings → Pages**, deploy from the `main` branch, and select the root folder.

All page imagery and animations are included in `assets/`. This package contains no Site credentials or Git history.
